# 🎓 SNHU Coursework Portfolio

A collection of projects and assignments from my B.S. in Computer Science program at Southern New Hampshire University, with a concentration in Software Engineering.

I use this repository to keep my coursework organized and have something to look back on as I continue learning and working on other projects.

- **Degree:** B.S. Computer Science (Software Engineering concentration)
- **GPA:** 3.8 / 4.0

## Coursework

### Completed

- **[CS-210 — Programming Languages](./CS-210-Programming-Languages/)**
  Comparative study of language paradigms with hands-on projects in C++ and Python, covering memory management, scripting vs. compiled workflows, and language design tradeoffs.

- **[CS-230 — Operating Platforms](./CS-230-Operating-Platforms/)**
  Exploration of operating systems and computer architecture with emphasis on Linux and Windows environments, process management, file systems, and deployment considerations.

- **[CS-250 — Software Development Lifecycle](./CS-250-Software-Dev-Lifecycle/)**
  End-to-end software development in an Agile setting, including requirements gathering, UML modeling, iterative implementation, testing, and retrospectives.

- **[CS-255 — System Analysis & Design](./CS-255-System-Analysis-And-Design/)**
  Analysis and modeling of business systems using UML. Includes use cases, activity diagrams, class diagrams, and sequence diagrams to drive software design decisions.

- **[CS-300 — Data Structures & Algorithms](./CS-300-DSA-Analysis-And-Design/)**
  Design and analysis of data structures and algorithms with focus on performance, efficiency, and problem-solving strategies.

- **[CS-305 — Software Security](./CS-305-Software-Security/)**
  Secure software design principles, common vulnerabilities, threat modeling, risk mitigation, and secure coding practices.

- **[CS-320 — Software Testing](./CS-320-Software-Test-Automation-QA/)**
  Principles of software testing, automated test frameworks, quality assurance practices, and test-driven development.

- **[CS-330 — Computer Graphics and Visualization](./CS-330-Computer-Graphics-Visualization/)**
  Development of interactive 3D graphics applications using C++ and OpenGL. Topics included transformations, textures, lighting models, camera systems, and real-time rendering. Final project involved recreating a real-world desk setup as a navigable 3D scene.

- **[CS-340 — Client/Server Development](./CS-340-ClientServer-Development/)**
  Development of database-driven applications using Python, MongoDB, PyMongo, CRUD modules, advanced queries, aggregation pipelines, and interactive dashboards.

- **[CS-350 — Emerging Systems Architecture and Technologies](./CS-350-EmbeddedSystems/)**
  Developed embedded systems using a Raspberry Pi and Python, including temperature monitoring and a thermostat prototype with sensors, GPIO controls, LCD output, and serial communication.

- **[CS-360 — Mobile Architecture and Programming](./CS-360-Mobile-App-Development/)**
  Developed an Android weight-tracking application using Java and SQLite, with user authentication, weight history, goal management, and SMS notifications.

- **IT-212 — Introduction to Computer Networks**
  Networking fundamentals including network architectures, protocols, addressing, hardware, security, and designing network solutions based on business requirements.

Each course folder typically contains some combination of source code, project files, documentation, and reflections.
