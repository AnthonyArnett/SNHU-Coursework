# CS340 Portfolio Reflection

### How do you write programs that are maintainable, readable, and adaptable?

I keep my code organized by separating different parts of the program. The CRUD module made it easier to reuse the database operations in Project Two without rewriting them. I could also reuse a similar module in future projects that use MongoDB.

### How do you approach a problem as a computer scientist?

I break a problem into smaller parts and work through each requirement individually. For this project, I started with the database and queries, then connected them to the dashboard and tested each feature. In the future, I would use the same approach to build around the client's requirements.

### What do computer scientists do, and why does it matter?

Computer scientsists use software and technology to solve problems. The Grazioso Salvare dashboard makes shelter data easier to search and understand, helping the organization find animals they meet its rescue requirements more efficiently.
